# Свои картинки для Meme Hype

Положите картинку в эту папку, назовите её по id мема и перезапустите сервер.
Всё: карточка покажет вашу картинку во весь размер, подписи мема останутся
поверх неё.

```
animals.16.m9.jpg     ->  мем animals.16.m9
ussr.18.m3.png        ->  мем ussr.18.m3
```

Форматы: `.jpg` `.jpeg` `.png` `.webp` `.gif`.

## Как узнать id мема

Из папки `backend`:

```bash
npm run memes                       # все мемы: id, откуда картинка, подписи
npm run memes -- --missing          # только мемы без картинки (рисуются эмодзи)
npm run memes -- --pack ussr --rating 18
npm run memes -- --html             # страница backend/meme-catalog.html со всеми карточками
```

Колонка источника: `custom` — ваша картинка, `found` — фото с Wikimedia
Commons (scripts/find-meme-images.js), `emoji` — картинки пока нет.
Команда также подскажет, если имя файла не совпало ни с одним мемом или файл
слишком тяжёлый.

Id мема — это `<набор>.<рейтинг>.m<номер по порядку в файле набора>`.
Наборы: `everyday` (МЕМЫ: Весело и в точку!), `ussr` (МЕМЫ 2: СССР и 90-ые),
`animals` (МЕМЫ 3: Котики и прочие нелюди). Рейтинги: `16` и `18`.

## Порядок выбора картинки

1. поле `image` у мема в файле набора (`backend/src/memehype/content/*.js`);
2. файл в этой папке;
3. найденное фото из `../manifest.json`;
4. иначе рисуются эмодзи мема.

Своя картинка всегда важнее найденной, так что неудачное фото достаточно
перекрыть своим файлом.

## Новый мем сразу со своей картинкой

Допишите мем **в конец** списка `memes` нужного рейтинга в файле набора и
укажите имя файла из этой папки (цвет фона — ключ из `palette` этого файла):

```js
['🐸', 'ВЕРХНЯЯ ПОДПИСЬ', 'НИЖНЯЯ ПОДПИСЬ', 'grass', { image: 'my-frog.jpg' }],
```

`image` может быть и полным адресом (`https://...` или `/...`). Дописывайте
в конец: id — это номер по порядку, и вставка в середину сдвинет id
следующих мемов (файлы, названные по id, «переедут» на соседние мемы).

## Советы

- Ширина около 600 px и вес до 600 КБ — карточки грузятся на телефонах.
- Карточка вертикальная (4:5), картинка обрезается по центру — главное
  держите в середине, сверху и снизу оставьте место под подписи.
- Мемы 16+ видят подростки: никакой обнажёнки, жестокости и т. п.
- Берите только то, что можно использовать: свои фото или картинки со
  свободной лицензией. Автора чужой картинки укажите у себя в проекте.
